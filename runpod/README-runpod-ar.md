# تشغيل المقدّمة على RunPod Serverless

RunPod بيشغّل **نفس** سكربت Kaggle (`kaggle/presenter_worker.py`) بس على كرت أسرع.
اللاب توب بيضل هو اللي بيدير كل شي (تحليل الموقع، القصة، التركيب، FFmpeg، الترجمة)،
و RunPod بيعمل بس الشغل التقيل على الـ GPU.

> ⚠️ RunPod مدفوع: بيحسب كل ثانية بيشتغل فيها الـ GPU، والتخزين الدائم (Network Volume) بيتحاسب عليه كل شهر.
> ما في شي بيشتغل إلا لما تكبسي **توليد**، وفي زر **إلغاء** بيوقف الدفع فوراً.

## 1. تخزين دائم للموديلات (Network Volume)

- RunPod → **Storage** → **New Network Volume**.
- الحجم: **150 GB**. الموديلات الحالية لحالها تقريباً 80 GB، وبدنا مكان للموديلات الجاية.
- اختاري Data Center فيه كروت 48 GB (مثلاً L40S / A6000).
- هون بتنحفظ الموديلات **مرة وحدة** (أول تشغيل بياخد وقت لينزّلها)، وبتنحفظ نتائج كل شغل لحتى اللاب توب ينزّلها.

## 2. الـ Endpoint

- RunPod → **Serverless** → **New Endpoint** → اختاري المصدر **GitHub**.
- المستودع: `mayaaljindy83-afk/MoneyPrinterTurbo`، الفرع `main`.
- **Dockerfile path:** `runpod/Dockerfile`، و **Build context:** جذر المستودع (`.`).
- **GPU:** الأفضل 48 GB. كرت 24 GB (4090) بيزبط كمان بس أبطأ شوي، لأنو ComfyUI بيضطر ينقل أجزاء من الموديل للذاكرة العادية.
- **Workers:** Active = 0 (ما بيندفع شي وقت ما في شغل)، Max = 1، Idle timeout = 60 ثانية.
- **Execution timeout:** 4 ساعات (البرنامج كمان بيبعت حد زمني مع كل شغل).
- **Advanced → Network Volume:** اختاري التخزين يلّي عملتيه بالخطوة 1.

## 3. المفتاح

- RunPod → **Settings → API Keys** → اعملي مفتاح جديد.
- انسخي كمان **رقم الـ Endpoint** من صفحة الـ Endpoint.
- بالبرنامج: صفحة **Presenter Video** → الخطوة 1 → اختاري **RunPod Serverless** → حطّي المفتاح ورقم الـ Endpoint → **Save & test**.
- المفتاح بينحفظ بس بملف `config.toml` عندك على اللاب توب، وما بينرفع على GitHub أبداً.

## كيف بيشتغل

1. البرنامج بيبعت الشغل (صوت المقدّمة وصورها، أقل من 7 MB) لـ RunPod.
2. RunPod بيولّد اللقطات وبيحفظها على الـ Network Volume. إذا طفيتي اللاب توب الشغل بيكمّل.
3. البرنامج بينزّل اللقطات قطعة قطعة، وبعدين بيمسحها من RunPod.
4. **كمّلي** بتجيب نتيجة آخر شغل **بدون** ما تبلّش شغل GPU جديد.

الأوقات (الانتظار بالطابور، التشغيل، التنزيل) واسم الـ GPU بينحفظوا بملف `runpod.json` جوّا مجلد الشغل.
